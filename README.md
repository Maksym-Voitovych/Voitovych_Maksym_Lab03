Ітератори, генератори та потокова обробка данихТема: Потокова обробка системи банківських рахунків (Варіант 4)   
Автор: Войтович Максим Андрійович (група ФеП-31)
Опис проєкту
Проєкт є продовженням системи управління банківськими рахунками.
 Мета — реалізація ітераційної моделі Python, генераторів, ледачих обчислень (lazy evaluation) та потокової обробки великих наборів даних без повного завантаження у пам'ять.   
 Ключові концепції та реалізовані можливості
 Ітератори та генератори: Власний ітератор AccountRangeIterator (__iter__/__next__), генераторні функції з yield, генераторні вирази (generator expressions).   
 Делегування (yield from): Рекурсивне розгортання вкладених структур даних.   Модуль itertools: Використання islice, groupby, accumulate, pairwise, chain.  
 Потоковий конвеєр (Lazy Pipeline): Послідовна обробка великого датасету (>100 000 записів) радяк за рядком із підтримкою пакетної обробки (batch processing) та запобіганням від'ємному балансу.   
 Аналіз продуктивності: Порівняння Eager (Pandas) та Lazy (Generators) підходів за часом виконання та піковим споживанням пам'яті (tracemalloc).
